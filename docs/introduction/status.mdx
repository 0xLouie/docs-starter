Linkr is launching in stages. This page is the single source of truth for what you
can use today. If another page describes something this page does not list as
available, treat this page as correct.

<Note>
**Last updated: July 2026.** Linkr is early. The public map and API cover New York
City only, and the mobile app is in invitation-only beta.
</Note>

## Available now

<CardGroup cols={2}>
  <Card title="Public web map" icon="map">
    Live at [linkrmap.com/demo](https://linkrmap.com/demo). A preview of the Linkr
    dataset: **78 hotspots across New York City** — Manhattan, Brooklyn, Queens, and
    the Bronx. Browse and filter without an account.
  </Card>
  <Card title="Public API" icon="code">
    A **read-only** REST API serving the same 78-hotspot NYC dataset. Three GET
    endpoints, no writes. See the [API reference](/docs/api-reference/overview).
  </Card>
</CardGroup>

The web map and API share one static NYC dataset. It is a **curated preview**, not a
live feed — the sample listings and owner handles illustrate what a populated Linkr
map looks like.

## In invitation-only beta

The **Linkr mobile app** is real and shipping to a small group of beta users. This is
where hotspots are actually created today.

<Info>
Access is **invitation only**, granted from the waitlist. The app is **not** on the
App Store or Google Play, and there is no public download link. When your invitation
is ready, we send you everything you need to install it.
</Info>

### Requesting access

<Steps>
  <Step title="Join the waitlist">
    Go to [linkrmap.com](https://linkrmap.com) and add your email.
  </Step>
  <Step title="Receive an invitation">
    Invitations go out from the waitlist in batches. There is no way to skip the
    waitlist today.
  </Step>
  <Step title="Install the beta">
    Your invitation email includes install instructions for the current beta build.
  </Step>
</Steps>

## Not available yet

To keep this honest, here is what Linkr does **not** do today. Do not rely on any of
it until this page says otherwise.

| Capability | Status |
|------------|--------|
| App Store / Google Play listings | Not yet — beta is invite-only |
| Web accounts or web login | Not yet — the web map has no login |
| Sync between the web and the app | Not yet — the web has no account layer |
| Coverage outside New York City | Not yet — NYC only |
| Live availability / uptime monitoring | Not yet — current data is static |

## What's coming next

Our near-term roadmap:

- Wider beta invitations from the waitlist
- Real hotspot persistence and accounts behind the app
- Expanding the map beyond the initial NYC dataset

---

The Linkr app is in **invitation-only beta**. This page explains how installation works
today.

<Info>
The app is **not** on the App Store or Google Play, and there is no public download
link. Access is granted from the waitlist. When your invitation is ready, we send you
install instructions for the current beta build.
</Info>

## Getting the app

<Steps>
  <Step title="Join the waitlist">
    Add your email at [linkrmap.com](https://linkrmap.com).
  </Step>
  <Step title="Receive your invitation">
    Invitations go out in batches. Your invitation email includes the install
    instructions for the current build.
  </Step>
  <Step title="Install and open">
    Follow the instructions in your invitation, then open the app to start exploring the
    map and sharing hotspots.
  </Step>
</Steps>

## The public map needs no install

If you only want to browse, you do not need the app at all. The public map runs in any
browser at [linkrmap.com/demo](https://linkrmap.com/demo), covering the 78-hotspot New
York City preview. It has no account and no login.

<Note>
The public map and the beta app are separate. The map is a curated preview; the app is
where beta users contribute hotspots. Data does not sync between them today — see
[Product status](/docs/introduction/status).
</Note>

## Updates

Because the app is in beta, updates are delivered through the same channel as your
invitation. Install instructions in your invitation email cover how to stay on the
latest build.
